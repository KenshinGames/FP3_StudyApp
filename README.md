# FP3級 合格ドリル(ブラウザ版)

公開URL: https://kenshingames.github.io/FP3_StudyApp/

3級FP技能検定(学科)の対策アプリ。ビルド不要の静的ページです。

## 見かた
- `index.html` をブラウザで開く(ダブルクリックでOK)
- スマホで見るとき: `python3 -m http.server 8000` → `http://<PCのIP>:8000`

## 機能
- 今日の10問(まちがえた問題・まだ解いていない問題を優先)/ 分野別 / 間違えた問題の復習 / ★を付けた問題(1問ごとに解説)
- 模擬試験(6分野×5問=30問・前の問題に戻って選び直せる・解説は最後にまとめて・60%で合格ライン判定)
- 4択と○×。選択肢は毎回シャッフル、キーボード(1〜4・Enter・←)でも操作可(キーの案内はスマホでは出さない)
- 実技(事例形式):事例文を読んで続けて答える。事例文は 2 問目からたたむ(タップで開く)。事例の一覧は分野ごと
- 途中でやめても・ページが読み込み直されても、ホームの「続きから」で再開できる
- iPhone のスワイプで戻る・ブラウザの戻るボタンで 1 つ前の画面へ(AIに質問のパネルは閉じる)
- ホーム画面に追加すると全画面で開き、電波がなくても問題を解ける(`manifest.webmanifest`・`sw.js`・`icons/`。ファイルを足したら `sw.js` の FILES にも足す)
- ホーム画面に追加の案内は端末・ブラウザごと(iPhone の Chrome は「共有 → 表示を増やす → ホーム画面に追加」、LINE などは Safari で開き直す手順)。設定の「やり方を見る」でいつでも見られる
- 記録の引き継ぎ:ブラウザとホーム画面のアプリ(Chrome と Safari も)は保存場所が別なので、設定の「記録の引き継ぎ」でコードをコピー → 貼り付けて移す
- 文字の大きさ(小・中・大)と効果音は、ホームの「設定」か問題の画面の「文字」ボタンで変える
- 解説ページの「💬 AIに質問する」:この画面の中でAIが答える(Cloudflare Workers AI の無料枠。[docs/ai-chat.md](docs/ai-chat.md)・`worker/`・`config.js`)。無料枠を使い切った日は ChatGPT / Claude を質問入りで開く
- 学習記録はブラウザの localStorage に保存(サーバー送信なし)

## 問題の足し方
`questions.js` に `Q(分野, 問題文, 正解, [誤り3つ], 解説)` または `T(分野, 問題文, true/false, 解説)` を追加するだけ。
実技の事例は `cases.js` の `K(分野, タイトル, 事例文, [[設問, 正解, [誤り3つ], 解説], ...])`(学習記録の番号がずれないよう、必ず末尾に足す)。

## 注意
問題・解説はオリジナル(AI作成)です。法令の数値は改正で変わるため、受検年度の公式テキストで確認してください。
