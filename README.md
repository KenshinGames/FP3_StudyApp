# FP3級 合格ドリル(ブラウザ版)

公開URL: https://kenshingames.github.io/FP3_StudyApp/

3級FP技能検定(学科)の対策アプリ。ビルド不要の静的ページです。

## 見かた
- `index.html` をブラウザで開く(ダブルクリックでOK)
- スマホで見るとき: `python3 -m http.server 8000` → `http://<PCのIP>:8000`

## 機能
- 模擬試験(6分野×5問=30問・解説は最後にまとめて・60%で合格ライン判定)
- ランダム10問 / 分野別 / 間違えた問題の復習(1問ごとに解説)
- 4択と○×。選択肢は毎回シャッフル、キーボード(1〜4・Enter)でも操作可
- 学習記録はブラウザの localStorage に保存(サーバー送信なし)

## 問題の足し方
`questions.js` に `Q(分野, 問題文, 正解, [誤り3つ], 解説)` または `T(分野, 問題文, true/false, 解説)` を追加するだけ。

## 注意
問題・解説はオリジナル(AI作成)です。法令の数値は改正で変わるため、受検年度の公式テキストで確認してください。
